# Gallery preview resources

Sample brand assets for the design-system catalog and SwiftUI previews only, so the Gallery pack can
be checked before an app (Munch) adopts it. Not used by any app's real screens.

- `GalleryPreview.xcassets`: Munch's Gallery colors from `munch/docs/design/tokens.json` (light and
  dark), named `GalleryPreviewBrand*` so they never replace an app's own `Brand*` colors.
- `Fonts/`: Instrument Serif and Geist, under the SIL Open Font License (`OFL-*.txt`).
